Пошаговая инструкция по запуску программы:
1. Установите GNU Make
2. Установите все файлы данного репозитория (mini_calc.y, mini_calc.l, calc3.h, MakeFile)
3. В cmd в директории, где находятся все файлы, пропишите команду make или make -f MakeFile
4. Пропишите ./calculator
ДОПОЛНЕНИЕ. Чтобы в vs code высвечивались конструкции из Lex/Yacc установите расширение Yash.
